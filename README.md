# NLMA都市計畫/國家公園使用分區圖連線

作者：Xing Li。版本：1.2.2。

在 QGIS 的外掛選單中加入都市計畫或國家公園使用分區 XYZ 圖層，或立即更新既有支援圖層。每 5 分鐘檢查連線，每 30 分鐘或連線授權失效時嘗試更新。外掛使用官方圖台提供的連線資訊；無法繞過網站驗證、存取限制或服務中斷。

## 安裝

使用 QGIS「管理與安裝外掛程式」的「從 ZIP 安裝」選取外掛 ZIP。最低版本沿用 3.24；本次測試版本為 QGIS 3.40.6。已開放 QGIS 4.0–4.2 安裝。使用者已於 QGIS 4.2.3 回報「可以用」；此回報未附逐項測試紀錄。本環境未直接測試 QGIS 4。

## 注意事項

需連線至 https://nsp.nlma.gov.tw/ 及 https://giss.nlma.gov.tw/ 。失敗時保留原圖層；尚未加入的圖層請在連線恢復後手動重試加入。加入後需移至相應都市計畫區或國家公園範圍查看。

連線 token 可能儲存在 QGIS 專案的圖層來源中。分享專案前請注意連線資訊可能過期；外掛日誌不會主動輸出 token。

此為第三方工具，非國土管理署官方外掛。圖資權利、使用條件及資料正確性以原服務提供者公告為準。

## 1.2.2 變更

- 更換圖示，修改外掛名稱及作者。
- 切換專案時取消舊請求，避免舊回應套用至新專案。
- 健康檢查收到 HTTP 401、403、498、499 時嘗試更新連線。
- 排除非有限圖磚原點及非整數縮放級別。
- 相容性上限設定為 4.2.99，設定 experimental=False；QGIS 4.2.3 已獲使用者回報可用。
